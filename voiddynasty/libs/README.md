# libs/ — dépendances locales non versionnées

Ce dossier doit contenir, pour compiler :

- `geckolib-fabric-26.3-5.5.7.jar` — https://modrinth.com/mod/geckolib (version Fabric 26.3)
- `voiddynasty-1.0.0.jar` (uniquement pour le projet `voiddynasty-bridge`) — le jar du mod, produit par `./gradlew build` dans `voiddynasty/`

Les `.jar` ne sont pas commités (binaires). Dépose-les ici avant de builder.
