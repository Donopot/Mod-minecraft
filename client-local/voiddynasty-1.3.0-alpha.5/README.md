# VOID DYNASTY 1.3.0-alpha.5 — HUD et raccourcis

Minecraft Java 26.3, Fabric Loader 0.19.5, Java 25. Rogue Trader reste facultatif. Ce pack conserve la navigation et les missions de l'alpha 4 et ajoute le HUD des armes et les raccourcis reconfigurables.

Fermer Minecraft, sauvegarder les mondes et remplacer les anciens JAR principaux par les quatre fichiers de `mods/`. Conserver un seul exemplaire du mod principal et de chaque dépendance. Le bridge 0.7.1, Fabric API et GeckoLib sont inchangés.

- **R** : recharger une arme à munitions tenue ; ce raccourci apparaît maintenant dans les contrôles.
- **J** : afficher ou masquer le HUD des armes, avec mémorisation du choix.
- Dans **Options → Contrôles → Affectation des touches → VOID DYNASTY**, modifier librement ces touches. Les choix existants sont conservés et les rappels du HUD les suivent.

Le HUD affiche l'arme, le chargeur, la réserve réellement utilisable, le nom des munitions et l'état du rechargement. Il est situé à droite au-dessus de la barre d'action centrale ; il respecte F1, les menus et le mode spectateur.

Le [guide commun](../../docs/HUD-KEYBINDINGS.md) décrit la cohabitation avec One Piece alpha 20 et les anciens R partagés. One Piece et ses ressources privées ne sont pas inclus dans ce pack public.
