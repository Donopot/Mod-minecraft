# Jouer à VOID DYNASTY en local

[Ouvrir le pack client unifié 1.3.0-alpha.8](voiddynasty-1.3.0-alpha.8), incluant le servitor alpha 7 et tous les correctifs du bridge dans le JAR principal.

Les packs historiques, dont [1.2.5](voiddynasty-1.2.5), [1.2.4](voiddynasty-1.2.4) et [0.7.1](voiddynasty-0.7.1), restent archivés sans changement.

Le pack alpha 8 contient trois JAR : VOID DYNASTY unifié, Fabric API et GeckoLib. Retirer l'ancien JAR principal et l'ancien bridge séparé avant de les copier dans `mods` de ton instance **Minecraft Java 26.3 avec Fabric Loader 0.19.5 et Java 25**. Aucun compilateur ni serveur séparé n’est nécessaire pour jouer en solo.

**Rogue Trader est facultatif.** Les armes, vaisseaux, blocs, coffres et correctifs du pad fonctionnent côté Minecraft. Les livraisons et récompenses dans Rogue Trader nécessitent son lancement et son module ; elles attendent lorsqu’il est fermé.

Les instructions complètes et les empreintes des fichiers sont dans le dossier du pack. Le pack ne contient pas Minecraft, Fabric Loader, Rogue Trader ni de sauvegarde.
