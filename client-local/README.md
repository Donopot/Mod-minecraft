# Jouer à VOID DYNASTY en local

[Ouvrir le pack client 1.2.4](voiddynasty-1.2.4), incluant le servitor corrigé et le bridge 0.7.1.

Le [pack historique 0.7.1](voiddynasty-0.7.1) reste archivé sans changement.

Le sous-dossier `mods/` contient les quatre JAR à copier dans le dossier `mods` de ton instance Minecraft **Java 26.3 avec Fabric Loader 0.19.5 et Java 25**. Aucun compilateur ni serveur séparé n’est nécessaire pour jouer en solo.

**Rogue Trader est facultatif.** Les armes, vaisseaux, blocs, coffres et correctifs du pad fonctionnent côté Minecraft. Les livraisons et récompenses dans Rogue Trader nécessitent son lancement et son module ; elles attendent lorsqu’il est fermé.

Les instructions complètes et les empreintes des fichiers sont dans le dossier du pack. Le pack ne contient pas Minecraft, Fabric Loader, Rogue Trader ni de sauvegarde.
