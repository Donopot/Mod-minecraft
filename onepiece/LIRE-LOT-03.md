# Essayer Mochi, Mori, Kira, Supa et Riki

Ouvre **Tester-Lot-03.cmd**, puis choisis un fruit. Le lanceur utilise un monde de laboratoire privé ; ferme sa fenêtre Minecraft pour arrêter aussi son serveur.

- **R** : technique sélectionnée ; **B** : suivante ; **F5** : caméra.
- **Muso Donatsu** : invoque les anneaux, attends la recharge, puis lance une autre attaque Mochi pour les faire réagir.
- **Diamond Body** : revêtement de durée fixe ; il expire automatiquement. Les lames Supa apparaissent pendant leurs techniques.
- Les cratères et blocs créés par les pouvoirs restent définitifs. Rouvrir le même fruit conserve le terrain sauvegardé.
- **Changer de fruit reconstruit volontairement la scène de laboratoire**, comme la commande `/dvisual`. Ce nettoyage du décor est distinct du comportement des pouvoirs.

Tester-OnePiece donne aussi accès aux fruits des lots précédents. Aucune installation habituelle ni partie VOID n’est modifiée. Le rendu reste une adaptation Minecraft ; l’avis artistique du joueur est encore attendu.
